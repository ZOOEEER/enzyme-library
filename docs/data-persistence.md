# 数据持久化

## 基本原则

- SQLite 是应用内的权威数据源。
- CSV 和 xlsx 用于模板、批量编辑和协作交换，不替代 SQLite 工作库。
- 列表字段只是本机显示偏好，不改变实际数据。
- 如需多个项目或多个数据版本，可以在设置页切换不同的 SQLite 数据库文件。

## CSV 交换

- `下载模板 CSV`：导出当前表的空模板。
- `导入 CSV`：按当前表主键新增或更新，不清空整表。
- `导出当前 CSV`：导出当前表全部数据，不受搜索和列表字段影响。
- `导出全部 CSV`：导出所有参与数据交换的表。
- CSV 导入时，未知旧列会被忽略；保存前仍需通过校验。
- 批量导入后建议运行 `整库校验`，检查必填字段、引用关系、单位和结构化结果。

## 设置、备份、恢复与切换

- 设置页显示当前 SQLite 数据库文件路径。
- `备份数据库`：把当前工作数据库复制到用户选择的位置；不会改变当前正在使用的数据库。
- `恢复数据库`：用用户选择的 SQLite 文件覆盖当前工作数据库；适合从备份回到某个历史状态。
- `切换数据库文件`：改用另一个 SQLite 文件作为当前工作数据库；不复制、不覆盖原数据库。
- 切换数据库适合维护多个项目库。选择不存在的新 `.sqlite` / `.db` 文件时，应用会自动初始化为空库。
- 为避免误选文件，应用会拒绝打开明显不是 Enzyme Library 的已有 SQLite 文件。
- 切换、恢复或批量导入后，建议运行 `整库校验`。
