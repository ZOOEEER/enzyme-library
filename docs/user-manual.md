# 用户手册

## 主界面

- 左侧是数据表导航，分为基础数据、活性数据和辅助数据。
- 左侧底部提供 `设置` 和 `帮助`。
- 顶部右侧提供 `整库校验`、CSV 模板下载、CSV 导入和导出等操作。
- SQLite 数据库路径、备份和恢复功能在 `设置` 页中查看和使用。

## 推荐录入流程

1. 先录入 `文献与来源`。
2. 再录入 `WT 酶/亲本酶`、`化合物`、`反应`、`实验条件`。
3. 最后录入 `WT 实验事实` 或 `酶工程事实`。
4. 录入完成后使用顶部高亮的 `整库校验` 检查必填字段、引用关系、单位和结构化结果。

## 基础数据

- `文献与来源`：记录论文、专利或其它数据来源。
- `WT 酶/亲本酶`：记录酶来源、序列、构建与表达/制备背景。
- `化合物`：记录化合物名称、SMILES、默认角色和结构信息。
- `反应`：定义酶促化学转化。
- `实验条件`：定义批次实验条件，可复用于不同酶/不同反应。

## 活性数据

- `WT 实验事实`：记录 WT/亲本酶在某反应和条件下的实验结果。
- `酶工程事实`：记录突变体及其相对 WT 的活性变化。

## 列表字段

- 表格上方的搜索框用于在当前表中快速筛选记录。
- `字段模式` 可在核心字段和全部字段之间切换；核心字段适合日常浏览，全部字段适合完整核对。
- `列表字段` 可自定义当前表显示哪些列；该设置只影响本机显示，不改变数据库和 CSV。
- 字段选择面板中，必填字段会加粗显示，便于优先检查。
- `恢复默认` 可将列表列恢复为系统推荐显示。

## 记录操作

- 点击 `新增` 可创建新记录；新增时可从已有记录复制内容，再修改后保存。
- 每行右侧 `编辑` 用于修改已有记录；编辑已有记录时编号字段不可修改，避免引用关系混乱。
- 每行右侧 `删除` 会移除当前记录。删除前请确认该记录没有被其它表引用；删除后建议运行 `整库校验`。
- 实践建议：优先用 `编辑` 修正已有记录，不要为了修改编号而删除重建；如果确需删除，先检查相关实验事实和引用字段。

## CSV 导入导出

- `下载模板 CSV`：导出当前表的空模板。
- `导入 CSV`：按当前表主键新增或更新，不清空整表。
- `导出当前 CSV`：导出当前表全部数据，不受搜索和列表字段影响。
- `导出全部 CSV`：导出所有参与数据交换的表。

## 受控词

- 受控词按业务域和单位类型分组展示。
- 左侧选择词表，右侧新增或删除词项。
- 删除受控词不会自动修改历史数据；整库校验会提示不在词表中的旧值。

## 帮助

- `用户手册` 说明日常录入和维护流程。
- `数据模型` 说明主要数据表、字段含义和填写规则。
- `数据持久化` 说明数据保存、CSV 交换、备份和恢复。
- 帮助内容在应用内部显示，不会打开外部浏览器或编辑器。
