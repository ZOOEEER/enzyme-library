# 产品需求说明

## 目标

开发一个离线 Standalone 桌面网页程序，用于 ?? 酶库数据录入、校验、导入导出和化合物即时渲染。

## MVP 功能

- 所有数据表的浏览、搜索、新增、编辑、删除。
- 基于 SQLite 的本地权威数据库。
- 按 `data_spec` Excel 多 sheet 模板导入/导出。
- 保存时和整库级分级校验。
- 受控词、字段说明、必填/建议字段提示。
- 表间关联字段提示。
- `Chemicals` 中 SMILES 2D 即时渲染。
- SQLite 数据库备份和恢复。
- Windows 安装包 exe 打包。

## 非目标

- 不做在线 UniProt/NCBI 自动补全。
- 不做 AI 文献抽取。
- 不做 3D 分子渲染。
- 不做 CSV/JSON 数据交换。
